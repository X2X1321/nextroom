Советы по использованию

Чтобы обратиться к нейросети, начните сообщение с указания провайдера: @openrouter, @groq, @cerebras или @routerai, либо по нику модели (который вы вписали @ник).

После отправки запрос будет обработан выбранной моделью, и бот ответит прямо в комнате.

Как получить API ключ Groq/Cerebras

Для использования сверхбыстрых моделей провайдера Groq/Cerebras вам понадобится бесплатный API ключ. Процесс получения займет всего пару минут:

  1. 1 Нажмите на кнопку Получить API Groq/Cerebras ниже, чтобы перейти на сайт провайдера.
  2. 2 Зарегистрируйтесь или войдите в свой аккаунт на сайте Groq/Cerebras.
  3. 3 Перейдите в раздел API Keys (в меню слева) и нажмите Create API Key.
  4. 4 Скопируйте ключ и вставьте его в поле "API Ключ" на этой странице, предварительно выбрав провайдера Groq/Cerebras.
