Мои ключи API (RouterAI)

Генерируйте ключи для интеграции моделей в сторонние приложения

Как использовать ключи?

Здесь вы можете сгенерировать персональные API-ключи RouterAI, привязанные к вашему балансу на сайте NextRoom.

  • Ключи имеют безлимитный лимит со стороны провайдера, но жестко зависят от вашего баланса здесь.
  • Если ваш баланс на NextRoom опускается до нуля или ниже, все ключи автоматически блокируются. При пополнении они снова активируются.
  • Эти ключи можно использовать в любых приложениях, поддерживающих OpenAI API формат, указав Base URL: https://routerai.ru/api/v1
